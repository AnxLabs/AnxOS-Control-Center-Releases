## Downloads

Each release may include some or all of the following artifact types:

- **Windows Setup installer** — the standard Windows installation package.
- **Windows portable executable** — a portable build that runs without installation.
- **Linux AppImage** — a self-contained AppImage for Linux.
- **Debian package** — a `.deb` package for Debian-based distributions.
- **SHA-256 checksums** — a `SHA256SUMS` file to verify downloaded artifacts.
- **Updater manifests** — auto-update metadata consumed by the application.

## Verification

Releases include a `SHA256SUMS` file so you can verify that downloaded artifacts are complete and unmodified. Compare the SHA-256 digest of a downloaded file against its entry in `SHA256SUMS` to confirm integrity.
